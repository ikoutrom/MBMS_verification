This folder contains the files from Section 5, "Extension to Lattice Discrete Particle Model"

The four subfolders correspond to the following cases:

- LDPM01_no_mass_scaling: Analysis without mass scaling
- LDPM02_uniform_mass_scaling: Analysis with uniform mass scaling
- LDPM03_MBMS_approach1: analysis using the proposed MBMS scheme, with the first approach for selective mass-scaling (= multiplying the mass matrix by a unique, scalar scaling factor, Equation 10)
- LDPM04_MBMS_approach2: analysis using the proposed MBMS scheme, with the second approach for selective mass-scaling (= separate scaling for individual LDPM tetrahedral "elements", Equation 11)

NOTE: the folder "LDPM04_MBMS_approach2" has two subfolders, corresponding to the runs with and without ACM part of response for the rotational dofs of the model.
