This folder contains the files from Section 4.2, "Analysis of cantilever elastoplastic column with shell elements"

The three subfolders correspond to the following cases:

- C01_explicit_unscaled: analysis without any mass scaling
- C02_explicit_MBMS_f21: analysis using the proposed MBMS scheme (time-step increase factor f = 21)
- C03_explicit_MS: analysis with uniform mass scaling
