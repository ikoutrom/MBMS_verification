This folder contains the files from Section 4.3, "Analysis of reinforced concrete wall under out-of-plane lateral loading"

The three subfolders correspond to the following cases:

- RC01_implicit_static: Implicit static analysis
- RC02_explicit_MBMS: explicit analysis using the proposed MBMS scheme (time-step increase factor f = 24)
- RC03_explicit_mass_scaling: explicit analysis with uniform mass scaling
